## 🚀 快速开始

### 本地运行

```bash
# 克隆项目
git clone https://github.com/你的用户名/你的仓库名.git
cd 你的仓库名

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

### 部署到Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/你的用户名/你的仓库名)

1. 点击上方按钮
2. 连接你的GitHub账号
3. 选择仓库
4. 点击Deploy

完成！获得你的专属链接！
