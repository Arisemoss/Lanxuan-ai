# 兰轩项目修复与优化 Spec

## Why
当前兰轩-三国杀1v1在线对战平台在武将技能逻辑、UI 渲染、移动端适配、GitHub 部署配置和后台健壮性等方面存在可修复的问题与可优化的体验。本变更在保持现有功能边界的前提下，修复明确 Bug 并做针对性优化，使项目更稳定、更易部署、体验更完整。

## What Changes
- 修复黄月英「奇才」技能只能弃置【无中生有】的问题，改为可弃置任意锦囊牌
- 修复游戏手牌在每次状态更新时重复播放发牌动画的问题
- 修复「退出」按钮逻辑与文案不一致的问题，统一为「投降」
- 替换 `index.html` 和 `README.md` 中的占位图/占位仓库链接，避免上线后展示无效内容
- 修正浅色主题下仍残留深色风格 CSS（半透明白边、阴影等）导致的视觉不协调
- 增加移动端基础入口，使隐藏侧边栏的关键信息可被查看
- 为后端 API 增加基础校验与速率限制，提升健壮性
- 优化信任度在聊天和游戏结束时的实际影响

## Impact
- 受影响能力：三国杀对战、武将技能、聊天 AI、前端视觉、GitHub 部署、后端 API
- 受影响代码：
  - `public/js/app.js`
  - `public/css/style.css`
  - `public/index.html`
  - `api/chat.js`
  - `api/server.js`
  - `api/data.js`
  - `README.md`

## ADDED Requirements
### Requirement: 后端基础防护
系统 SHALL 对聊天和数据 API 增加基础输入校验与速率限制，避免空消息、超大请求和简单滥用。

#### Scenario: 非法请求被拒绝
- **WHEN** 用户发送缺少消息内容或内容过长的聊天请求
- **THEN** 服务端返回 400 错误并给出清晰提示

### Requirement: 移动端基础可用
系统 SHALL 在屏幕宽度较小时提供可查看侧边栏信息的入口，避免完全无法看到好感度/对局记录。

#### Scenario: 移动端查看状态
- **WHEN** 用户在小屏设备打开页面
- **THEN** 可通过新增入口查看左侧个人状态或右侧对局记录

## MODIFIED Requirements
### Requirement: 黄月英「奇才」技能
原实现只能弃置【无中生有】，与技能描述「任意锦囊牌」不符。系统 SHALL 允许黄月英弃置 `ghcq`、`nmrr`、`wjqf`、`wzsy` 中的任意一张锦囊牌来发动技能。

#### Scenario: 发动奇才
- **WHEN** 玩家选择黄月英并持有任意锦囊牌
- **THEN** 点击技能按钮可弃置该锦囊牌并摸两张牌

### Requirement: 手牌动画稳定性
系统 SHALL 仅在牌堆真正发生变化时播放发牌动画，避免每次渲染都重新触发。

#### Scenario: 正常游戏
- **WHEN** 玩家摸牌、出牌或 AI 行动后状态刷新
- **THEN** 已存在的手牌保持静止，新增/变化的手牌才播放动画

### Requirement: 退出按钮语义
系统 SHALL 将游戏内「退出」按钮统一为「投降」行为，并给出对应提示。

#### Scenario: 点击退出
- **WHEN** 玩家在对局中点击退出/投降按钮
- **THEN** 按投降逻辑结算并展示「你投降了」弹窗

### Requirement: 浅色主题视觉一致性
系统 SHALL 修正 CSS 中针对深色主题残留的 `rgba(255,255,255, ...)` 描边、阴影，使整体视觉在蓝白浅色主题下协调。

#### Scenario: 页面正常浏览
- **WHEN** 用户浏览聊天、武将选择、游戏界面
- **THEN** 卡片、血条、游戏背景等元素的边框/阴影与浅色主题一致

### Requirement: 信任度生效
系统 SHALL 让信任度在本地回复选择和游戏结算时产生可见影响（如影响回复语气、好感度加成倍率）。

#### Scenario: 高信任度互动
- **WHEN** 玩家信任度较高且触发好感度变化
- **THEN** 实际好感度变化获得小幅正向加成

## REMOVED Requirements
### Requirement: 占位资源直接上线
**Reason**：`index.html` 的 OG/Twitter 图片与 `README.md` 的仓库链接均使用占位符，直接部署会展示无效信息。
**Migration**：替换为项目相关真实图片或本地生成图片，README 中仓库链接替换为可配置的占位说明或真实链接。
